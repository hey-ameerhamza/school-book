## Overview

SchoolBook is a small, simple study workspace inspired by tools like Google NotebookLM. It brings notes, flashcards, a study timer and a distraction-free focus mode into one website, so students can study better and stay focused.

The project is developed for **Information & Communication Technology (CSL-114)**, BS(CS)-1C, under **Ms. Nadia Kalsoom**.

## The Problem

| Problem | Impact |
| --- | --- |
| Notes are spread over many apps, files and copies | Students waste time finding what they need |
| Making flashcards by hand takes a long time | Students revise less before tests |
| Phones and other websites distract students | Study time is lost and focus is weak |
| Most tools have one fixed look | Eyes get tired during long study sessions |

## Features

- **Notes**: create, edit, delete and search notes by title or text
- **Flashcards**: build question and answer cards, flip them, and mark them as known or review again
- **Important list**: star notes and cards and see them all on one page
- **Study timer**: start, pause and reset
- **Focus mode**: hides extra menus and items while you study
- **Themes**: light, dark, sepia and more
- **Responsive design**: works on mobile, tablet and desktop
- **Private by design**: data is saved in your browser and never leaves your device

## Getting Started

```bash
# Clone the repository
git clone https://github.com/hey-ameerhamza/school-book.git

# Open the project folder
cd school-book
```

Then open `index.html` in any modern browser. No build step, server or installation is needed.

## Project Scope

**Included:** six pages, notes, flashcards, important list, study timer, focus mode, themes, and a mobile and desktop layout.

**Not included:** user accounts, a back-end server, AI answers and a mobile application.
